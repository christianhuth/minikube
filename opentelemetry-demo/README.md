# OpenTelemetry Demo

This small demo project shows how to use OpenTelemetry:

## Start a Minikube Cluster (optional)

```bash
./00-start-minikube.sh
```

## Install the OpenTelemetry Demo

```bash
./01-install-opentelemetry-demo.sh
```

## Access Argo CD UI

```bash
minikube tunnel
```

Open https://otel-demo.127.0.0.1.nip.io in your Browser.
